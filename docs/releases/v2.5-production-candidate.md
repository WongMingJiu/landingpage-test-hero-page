## V2.5 解决了什么

V2.5 是文本链（V2.1a 创意标签 → V2.1b 意图决策 → V2.3 消息匹配文案）的
**稳定性校准与生产候选固化**阶段，共六轮离线验证（A→F）：

1. **Same Model Replay（A）**：把评测器与生成链解耦归因，确认系统设计层的
   不稳定来源（CASE B）。
2. **Semantic Priority（B）**：V2.1a/V2.1b 修复「CTA / 稀缺 / 领取信息
   覆盖主体叙事」——新增 Semantic Priority 与 Primary Eligibility 五条件，
   V2.1b Rule 3 加最小继承约束；B1 修复 3/3 对齐，v04 漂移改道判方向 B。
3. **Narrative Dominance（C）**：压制 v04 三条解释路径漂移（学员故事证明型
   → 获得可复制学习范例 → 复制学员成功路径），v04 修复为 WARN 完美收敛。
4. **Opening Stability（D）**：Opening Type 冲突仲裁（第一有效 Decision
   Window 优先权 Rule A-D），v03/v04/v06 三个 regression anchor 全保持。
5. **Full Repeat Stability（E）**：v01-v10 全量 3× 重复稳定性测试
   （90 stages，gpt-5.5/temp=0），识别出四类漂移信号并完整归因。
6. **Production Gate（F）**：校准三层判定口径——Semantic Stability
   Gates（V2.1b route / V2.3 SAC / E2E MRD）、Structural+Safety Gates
   （0 容忍，含新增 used_anchors membership validator）、Observability
   （中间漂移降级 WARN 持续监控）。

## 为什么当前版本可 Freeze

V2.5-F Production Gate 六项冻结条件全部通过（人工评审已确认）：

```text
V2.1b Route Stable        30/30
V2.3 Same Answer Class    30/30
E2E Material Route Drift  0/30
v04 Structural Hard Fail  0/3
Compliance Hard Fail      0
Grounding Safety Fail     0
```

核心理由：生产链路的产出是「落地页回答什么问题、用哪条转化路径说服用户」。
gpt-5.5/temp=0 对双信号素材存在约 1/3 的中间分类摇摆（模型能力物理边界），
但 V2.1b/V2.3 对上游摇摆表现出完全的收敛性（30/30 route + 30/30 SAC）；
结构/安全项由程序化 validator 0 容忍拦截。据此把中间摇摆降级为 observability
监控、把端到端决策稳定性与结构安全设为阻断门槛，是工程上可执行的生产标准。

Freeze 前最终验证：全量单测 122/122 PASS；v03/v04/v06 冻结冒烟
（各一次完整文本链，不生图）3/3 通过（详见 Freeze Result 报告）。
