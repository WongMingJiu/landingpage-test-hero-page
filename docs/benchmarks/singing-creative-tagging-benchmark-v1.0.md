# Singing Creative Tagging Benchmark V1.0

> 用途：V2.1a Creative Tagging 的 Seed Ground Truth
>
> 样本：10 条真实唱歌投放素材
>
> 决策原则：默认只使用前 30 秒的完整多模态信息；只有多模态语义不足时才扩到 60 秒。

---

## 1. Ground Truth 口径

本 Benchmark 不做“完整视频总结”，而是模拟用户点击/流失前的广告理解。

因此所有 Ground Truth 首先基于：

```text
0–30s transcript
+ 画面字幕
+ 实际人物/动作/演唱
+ 场景和反应镜头
+ 前30s分镜
```

而不是根据 60–180 秒完整脚本补全。

### 1.1 Benchmark 输出

每条素材记录：

- Decision Window；
- Active Value Tags；
- Opening Type；
- User Expectation；
- 关键证据；
- 边界说明（如有）。

`P` = Primary Salience，`S` = Supporting Salience。

# 3. 逐条证据

## v01 — 混剪·素人演绎

### 关键前30s证据

- 0–2.5s：三位女性剧情演绎，横幅“宋老师收到学员反馈…轻松唱歌法有多神奇？”；
- 5–15s：老年学员林女士对麦演唱；横幅“改掉喉咙唱歌 其实你也很会唱”；
- 17.5s：宋伶俐出镜，出现“国家一级演员”和“4天身体唱歌体验营”；
- 20–27.5s：电子琴前口播 + 手机课程画面。

### Ground Truth

```text
Opening Type: 学员故事证明型
User Expectation: 复制学员成功路径
```

Active Value Tags：

```text
P 获得可复制学习范例
P 获得演唱效果参照
S 正确发声并保护嗓音
S 获得专业指导
S 获得课程与学习资源
```

### 判定说明

开头先设问“轻松唱歌法有多神奇”，随后直接给出学员演唱证明，再进入老师/课程。学员身份和结果是前段核心社会证明，不应被后续老师身份或课程露出覆盖。

## v02 — IP8·换前贴

### 关键前30s证据

- 0–12.5s：老师持麦站在《梅花泪》简谱前教唱，指示杆点谱；
- 15–22.5s：老师琴前口播“饭后半小时…从现在开始”，同时显示“国家一级演员”；
- 25s：线下课堂“老师现场指导”；
- 27.5s：“现在我们就简化流程”。

### Ground Truth

```text
Opening Type: 教学演示型
User Expectation: 掌握简单方法
Confidence: medium
```

Active Value Tags：

```text
P 获得专业指导
P 获得演唱效果参照
S 方法简单易操作
S 降低时间与地点限制
```

### 边界说明

老师确实在演唱，因此 `演唱效果型` 是可理解候选；但画面是对着简谱点谱教唱，原 Opening Taxonomy 将“歌曲带练”纳入教学演示，且教学演示优先级高于演唱效果，因此正式答案定为 `教学演示型`。

# 4. Benchmark 关键断言

## 4.1 Decision Window

10 条样本在加入真实画面后，0–30 秒均具有足够多模态语义。

因此正常模型结果应为：

```text
extended = false
used_seconds = 30
```

如果模型仅因为 transcript 稀疏而扩到 60 秒，应判为 Decision Window 逻辑错误。

## 4.2 Opening / Expectation 不做机械映射

以下样本必须用于验证两者独立判断：

```text
v03:
Opening = 演唱效果型
Expectation = 复制学员成功路径

v05:
Opening = 演唱效果型
Expectation = 理解专业原理

v07:
Opening = 演唱效果型
Expectation = 复制学员成功路径
```

## 4.3 边界题

优先保留：

```text
v02：歌曲带练 vs 演唱效果
v10：师生同唱 + 方法字幕 vs 演唱效果
```

这两条不应从 Benchmark 中删除，因为它们可以有效检测模型是否真正使用原 Taxonomy 边界和优先级。

## 4.4 后段不能篡位

v04 是标准测试题：

```text
前20s：学员故事/效果
22.5s后：课程即将停止 + 抢课
```

正式判断仍以已经成立的前段 Intent 为主。
