## 2. Replay 命令

```bash
set -a && source config.env && set +a
# 单次 replay：工件 + 转写 + taxonomy -> creative_tagging_v1（零视频抽取、零多模态证据抽取）
python3 -m v2.benchmarks.adjudication_stability \
    --evidence output/v01/v2/structured_evidence.json --repeats 1
```

工件缺失时可用 `--video <mp4>` 一次性构建（需活跃多模态 provider）：

```bash
python3 -m v2.benchmarks.adjudication_stability \
    --evidence output/v05/v2/structured_evidence.json \
    --video benchmarks-local/singing-creative-tagging-v1.0/videos/v05.mp4 --repeats 3
```

## 4. 固定证据决策是否稳定（诊断结果）

Provider 切换验证：`llm.gw.dachensky.com`（gpt-5.4 / grok-4.6）在大终审负载下持续上游超时；
切到 `https://opencode.ai/zen/go` + `qwen3.7-plus`（经 `provider.py` 适配器，零产品改动）后，
3 视频 × 3 轮共 9 次终审全部完成（约 37 分钟，含少量 schema 自动重试）。**薄适配器按预期工作。**

| 视频 | Opening ×3 | Expectation ×3 | Primary Core ×3 | 振荡 |
|---|---|---|---|---|
| v01 | 学员故事证明型 ✓稳定 | 复制学员成功路径 ✓稳定 | partial/wrong/partial（run1 丢一个 primary） | 无 |
| v02 | 演唱效果型 ✓稳定 | 获得/复制演唱效果×2 / 低门槛开始学习×1 ✗不稳定 | partial/wrong/partial | 无 |
| v04 | 学员故事证明型 ✓稳定 | 复制学员成功路径 ✓稳定 | wrong/partial/partial | 无 |

**结论：**
- **Opening：固定证据下 3/3 样本完全确定** —— 结构化证据 + 受限终审消除了 Opening 语义漂移。
- **User Expectation：8/9 轮恒等，1 轮漂移**（v02：获得/复制演唱效果 ↔ 低门槛开始学习）——该边界（v02 正是历史回归案例）在证据完全固定时仍偶发漂移，属终审判断残余非确定性，非中间层问题。
- **Primary Core：无 wrong↔exact 大幅振荡**，但 primary 集合在样本内漂移（1-2 个 primary 的取舍），对齐在 exact/partial/wrong 间波动；salience 选择仍是最大漂移源。
- 本轮为**诊断性**结果：仅 3/10 视频有证据工件，不替代 E2E 基准。

## 5. 仍需活跃多模态 provider 的验证

1. **其余 7 个视频（v03/v05-v10）的证据工件构建**（多模态证据提取不可 replay）。
2. **10×1 准确率门槛**：Opening ≥9/10、Expectation ≥9/10、Core aligned ≥8/10、Window 10/10、Evidence 10/10。
3. **10×3 E2E 稳定性终门**：Window 30/30、Opening 稳定（仅允许文档化备选）、Expectation ≥9/10 样本稳定、Core 每轮 ≥8/10 且无 wrong/exact 振荡。
4. E2E 路径中证据提取层本身的确定性（工件只冻结"已提取"的证据；提取层漂移需活跃 provider 验证）。

注：`opencode.ai/zen/go` 探测与 replay 均正常（文本 ~19s、6 图 ~8s、终审 1-8 分钟/次），可作为 E2E 重跑的候选 provider。

## 6. 最终建议

**DO NOT PASS**（V2.1a 维持 Feature Pass / Stability Pending）

理由：固定证据下 Opening 已完全确定（核心诊断假设被证实：自由文本中间层确为主漂移源，结构化证据已消除之），
但 ① Expectation 在 v02 边界仍有 1/3 漂移；② Primary salience 选择仍在样本内漂移，Core 未达每轮 ≥8/10 aligned；
③ 10 视频 E2E 准确率与稳定性终门尚未在活跃 provider 下执行（仅 3/10 工件）。
后续只需在新 provider 上补齐 7 个工件并重跑两个终门；**无需再做产品/决策层改动**——除非 E2E 结果复现 v02 Expectation 漂移，届时才考虑窄边界澄清。
