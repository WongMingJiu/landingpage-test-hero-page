## 识别方式 / MVP 规则

| 规则项 | MVP规则 |
|---|---|
| 片头识别单元 | 第一有效脚本片段，以及与该脚本片段时间范围重叠的所有分镜。 |
| 第一有效脚本 | 在真实素材边界内按开始时间排序，选择第一段非空、非纯尾帧误切且可解析的脚本片段。 |
| 钩子痛点 | 仍取第一有效脚本片段中的pain_topics，与片头综合类型分别保存。 |
| 多分镜选择 | 先排除无有效画面、转场和装饰素材；优先选择与脚本策略语义匹配的分镜；再按重叠时长最长、开始时间最早决胜。 |
| 脚本多标签 | 将每个二级标签映射到候选片头类型，按照MVP决策优先级输出一个片头综合类型，同时保留全部原始标签。 |
| 分镜覆盖 | 分镜通常用于确认呈现形式和提高置信度；只有演唱前后对比等强视觉证据可以覆盖普通脚本类型。 |
| 脚本缺失 | 使用第一有效分镜进行视觉兜底，并将opening_source_mode标为visual_only。 |
| 画面缺失 | 按脚本策略输出片头类型，opening_source_mode=script_only，置信度最多为中。 |
| 无有效信息 | 脚本与画面均不足时输出其他/无法判断，不根据课程知识库补猜。 |

## 决策优先级

| 决策优先级 | 脚本条件 | 分镜条件 | 输出片头综合类型 | 说明 |
|---:|---|---|---|---|
| 1 | 强效拦截/拟态归属 | 人物口播 | 强拦截口播型 | 显式强拦截优先于同片段中的福利、承诺和CTA |
| 2 | 任意效果/成果表达 | 演唱效果-演唱前后对比 | 效果对比型 | 前后对比是强视觉证据，优先于普通演唱展示 |
| 3 | 实操教学 | 教学演示 | 教学演示型 | 脚本和画面共同呈现可操作方法 |
| 4 | 效果呈现 | 演唱效果 | 演唱效果型 | 直接用演唱结果吸引 |
| 5 | 反常识/悬念制造 | 任意有效画面 | 反常识/悬念型 | 说服策略优先，视觉只决定置信度 |
| 6 | 警示提醒/数据冲击/沉没成本/负面后果 | 任意有效画面 | 警示/数据冲击型 | 风险和损失是开头主要驱动力 |
| 7 | 共情提问/痛点类 | 人物口播/场景化演绎/图文 | 痛点共鸣型 | 用户问题是开头主要信息 |
| 8 | 科普内容 | 人物口播/教学演示/图文 | 知识科普型 | 以解释原理建立观看价值 |
| 9 | 用户故事/成果背书/学员背书/从众引导 | 学员案例/人物口播/演唱效果 | 学员故事证明型 | 他人经验和结果是主要证据 |
| 10 | 资历/传承/机构/社会影响力 | 权威展示/人物口播 | 权威背书型 | 专业身份和可信度优先 |
| 11 | 利益福利或稀缺预告 | 任意有效画面 | 利益福利前置型 | 课程权益、价格或稀缺性前置 |
| 12 | 效果/服务/产品承诺 | 任意有效画面 | 承诺保障前置型 | 先降低结果和服务不确定性 |
| 13 | 课程内容引导 | 任意有效画面 | 课程内容导览型 | 按问题或课时介绍课程结构 |
| 14 | 便利性/领取流程/零基础保障 | 任意有效画面 | 低门槛领取型 | 降低学习或领取阻力 |
| 15 | 行动指令/价值引导/选择引导/课程尾帧 | 任意有效画面 | 行动引导型 | 直接推动点击、领取或报名 |
| 16 | 剧情/花絮/受访演讲/人物传记 | 任意有效画面 | 剧情/内容叙事型 | 叙事形式本身是开头主要特征 |
| 90 | 脚本无明确策略 | 课程/产品展示或图文包装 | 图文/课程展示型 | 仅作为视觉驱动兜底 |
| 99 | 脚本和视觉均不足 | 无有效画面/一般素材 | 其他/无法判断 | 进入质量复核，不强行推断 |

## 实现约束

- 最终只输出一个 `opening_type`。
- 默认优先级只用于同一有效开头单元中存在多个候选策略时决胜，不允许后段信息覆盖已经成立的前段主权。
- `脚本缺失 / 画面缺失 / 无有效信息` 的处理必须按上表执行。
- 具体输出 Schema、Evidence 与 Confidence 规则以 `docs/v2.1a-creative-tagging-spec-v1.0.md` 为准。
