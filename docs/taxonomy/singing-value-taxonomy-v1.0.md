# 唱歌 Value Taxonomy V1.0

> 状态：Canonical / Implementation Source
>
> 原始来源：`素材级标签文档（初稿）` → Sheet `唱歌补充价值标签(新-需拓展)`
>
> 用途：V2.1a Creative Tagging 的 Value Taxonomy。本文忠实转录原表，不新增、不改写标签定义。
>
> 规模：7 个一级标签，36 个二级标签；原表中 36 个二级标签均标记 `MVP启用=是`。

## 使用约束

- 实现时必须同时使用 `价值二级标签 + 标签描述 + 识别示例`，不得只使用裸标签名。
- 标签输出名称必须与本文逐字一致。
- Value Tag 可多选；`matched_value_tags` / `active_value_tags` 的筛选、Evidence Strength、Salience 与数量约束以 `docs/v2.1a-creative-tagging-spec-v1.0.md` 为准。
- 本文是标签定义资产，不替代 Spec 中的跨标签边界规则。

## 演唱能力

| 价值二级标签 | 标签描述 | 识别示例 | MVP启用 |
|---|---|---|---|
| 稳定气息 | 帮助用户改善气息不足、断气或气息不稳，使气息更通畅稳定。 | 气息更稳、上气不接下气得到改善 | 是 |
| 改善音色与声音质感 | 帮助用户改善大白嗓、声音单薄等问题，使歌声更圆润、通透、悦耳或具有混响。 | 摆脱大白嗓、歌声自带混响 | 是 |
| 增强声音稳定与力量 | 帮助用户减少声音虚、抖、飘，增强声音稳定性、穿透力和力量感。 | 声音不再发虚发抖、歌声更有力量 | 是 |
| 正确发声并保护嗓音 | 帮助用户找到正确发声位置，减少喉咙用力、声音卡住或伤嗓风险。 | 找对发声部位、不伤嗓子、声音不卡在喉咙 | 是 |
| 突破高音 | 帮助用户更轻松、稳定地完成高音。 | 高音轻松、以前不敢唱的高音也唱上去 | 是 |
| 突破低音 | 帮助用户完成低音或改善低音下不来的问题。 | 低音下得来 | 是 |
| 顺畅音域转换 | 帮助用户在高中低音之间顺畅切换。 | 高中低音自如切换 | 是 |
| 改善音准并减少跑调破音 | 帮助用户唱得更准，减少跑调、破音或音准不稳。 | 唱歌不再跑调、声音更准 | 是 |
| 增强情感表达 | 帮助用户唱出更有感情、更有意境和感染力的歌声。 | 歌声更有感情、唱出有情感的歌声 | 是 |
| 掌握通用演唱能力 | 帮助用户获得可迁移到多首歌曲的通用演唱能力。 | 不管唱什么歌都好听、唱好所有通俗歌曲 | 是 |

## 心理障碍突破

| 价值二级标签 | 标签描述 | 识别示例 | MVP启用 |
|---|---|---|---|
| 敢于开口演唱 | 帮助用户克服不敢唱、害怕开口或在人前演唱的心理障碍。 | 从不敢唱到大胆开口 | 是 |
| 建立演唱自信 | 帮助用户减少自我怀疑，增强对自己歌声和学习能力的信心。 | 越唱越自信、自信开口唱 | 是 |
| 降低天赋与嗓音条件焦虑 | 帮助用户克服认为自己没有天赋或先天嗓音条件差的担忧。 | 不需要天赋、没有优越嗓音也能学 | 是 |
| 降低年龄焦虑 | 帮助用户降低因年龄较大而担心学不会、练不好的焦虑。 | 年纪大也能学、中老年友好 | 是 |

## 学习降阻

| 价值二级标签 | 标签描述 | 识别示例 | MVP启用 |
|---|---|---|---|
| 零基础可学 | 降低基础要求，让没有唱歌基础的用户也能开始学习。 | 零基础小白也可以轻松学 | 是 |
| 方法简单易操作 | 降低动作和练习难度，让用户容易理解、模仿和执行。 | 几个简单动作、看得见摸得着的训练 | 是 |
| 降低乐理与理解门槛 | 减少复杂乐理、专业术语或抽象理解造成的学习障碍。 | 不讲复杂乐理、没有理解门槛 | 是 |
| 降低时间与地点限制 | 支持用户利用碎片时间，在家或通过手机灵活学习。 | 一部手机在家学、有空就看、每天十五分钟 | 是 |
| 支持反复学习 | 通过课程回放或反复观看，降低跟不上和遗忘风险。 | 课程支持反复回看、无限回放 | 是 |
| 获得辅导与答疑 | 通过助教、辅导或答疑帮助用户解决练习中的具体问题。 | 助教针对性辅导、辅导老师指导答疑 | 是 |
| 获得系统学习路径 | 通过课程结构、分课安排或循序渐进的路径降低学习迷茫。 | 第一课到第五课分别解决不同问题 | 是 |

## 专业认知提升

| 价值二级标签 | 标签描述 | 识别示例 | MVP启用 |
|---|---|---|---|
| 识别自身唱歌问题 | 帮助用户识别自己存在的具体唱歌问题或问题组合。 | 上气不接下气、大白嗓、高音困难等问题清单 | 是 |
| 纠正错误唱歌认知 | 帮助用户修正关于嗓子、天赋或传统练习方式的错误认知。 | 唱歌靠的不是嗓子，而是身体 | 是 |
| 理解发声原理 | 帮助用户理解气息、腔体、身体通道、肌肉或发声位置等原理。 | 打开身体通道、激活肌肉、找到发声位置 | 是 |
| 明确问题解决路径 | 帮助用户知道不同问题应该学习什么内容、采取什么步骤。 | 想解决气息看第一节课，想学高音看第三节课 | 是 |
| 获得演唱效果参照 | 通过演唱或练习结果，为用户提供什么是好效果的直观参照。 | 实际演唱片段、老师评价“非常好” | 是 |
| 获得可复制学习范例 | 通过学员故事、跟练或成果案例，让用户看到可参考的学习路径。 | 学员跟练后立竿见影 | 是 |

## 信任保障

| 价值二级标签 | 标签描述 | 识别示例 | MVP启用 |
|---|---|---|---|
| 获得专业指导 | 让用户获得来自专业身份、长期经验或权威机构的可靠指导。 | 国家一级演员、三十多年教学经验 | 是 |
| 获得效果与服务保障 | 通过效果承诺、课程安排、回放或服务支持降低学习结果的不确定性。 | 不怕学不会、助教辅导、课程可回看 | 是 |
| 减少试错与选择成本 | 帮助用户减少在不同方法、老师或课程之间反复试错和选择的成本。 | 总结三十多年经验、正版方法、无需网上到处找教程 | 是 |

## 课程权益

| 价值二级标签 | 标签描述 | 识别示例 | MVP启用 |
|---|---|---|---|
| 获得课程与学习资源 | 让用户获得课程、课程视频、练习资料或配套学习资源。 | 领取四天身体唱歌课程到手机 | 是 |

| 明确学习入口 | 告诉用户在哪里以及如何进入学习、领取或报名流程。 | 点击下方链接、学唱歌就上兴趣岛 | 是 |
