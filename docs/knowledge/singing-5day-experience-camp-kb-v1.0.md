# 2. Product Identity

## 2.1 正式产品名称

**5 天身体唱歌体验营**

## 2.2 核心产品定位

面向中老年与唱歌零基础 / 弱基础用户，通过宋老师“身体歌唱法”进行简单、可跟练、强调动作与歌曲实操的唱歌入门体验。

核心理念可概括为：

> 摒弃错误的用嗓方式，用身体唱歌；通过身体通道、气息、腔体和身体力量的协调，让普通人找到更轻松、更正确的发声方向。

注意：以上是产品方法方向，不等于对所有用户承诺固定学习结果。

## 2.3 用户适配事实

可用于理解策略：

- 课程主要面向中老年群体；
- 大量用户为 50+；
- 用户中零基础 / 未系统学习者占比较高；
- 常见问题包括气息不足、大白嗓、喉咙用力、高音困难、高低音转换、节奏与音准等；
- 用户常见 Barrier 包括年龄、零基础、怕专业声乐难学、不知道从哪里开始、自己练没人指导等。

这些用户画像用于策略判断，不允许被改写成无证据的个体诊断。

# 4. Problem → Method → 5-Day Course Supply Map

这是 V2.2 最重要的 Product Truth 层。

| 用户问题 / Barrier | 可使用的方法与机制 | 5 天体验营真实承接 | 可形成的 Hero 方向 |
|---|---|---|---|
| 大白嗓、声音缺少质感 | 打开身体通道、丹田发力、身体力量参与发声 | D1《告别大白嗓，找到丹田发力点》 | 正确发声不是只靠嗓子，可以从身体通道和发力方式开始练 |
| 气息不足、气息不稳、唱两句没气 | 内鼻孔吸气、气息训练、啃苹果训练 | D2《稳固气息，实现大胆自信开口唱》 | 气息问题有具体可练习的方法，而不是只能靠天赋 |
| 不敢开口、唱歌没自信 | 气息稳固 + 跟练 + 歌曲实践 | D2 | 从能跟练的基础方法开始，逐步建立开口唱的信心 |
| 高音上不去 | 横通道训练、打开内口腔、高位置发声 | D3《体验高位置演唱，轻松上高音》 | 高音可以从发声位置和身体空间入手，而不只是硬喊 |
| 挤嗓、卡嗓、喉咙用力 | 打开身体 / 腔体通道、高位置发声、身体力量控制嗓音 | D1、D3；另有福利课《摆脱挤嗓卡嗓，歌声嘹亮有空间》 | 先纠正错误用嗓，再学习身体参与发声的具体路径 |
| 高低音切换困难 | 低频 `wu` 音训练、高位置发声训练 | D4《高低音自如切换，唱歌有感情》 | 高低音切换存在具体练习路径 |
| 唱歌缺少情感 | 高低音切换、深情演唱实操 | D4 | 技术训练可以进一步服务歌曲情感表达 |
| 学新歌没方法 | 气包声、高位置稳定训练 | D5《通俗演唱万能功法，一招走天下》 | 学歌可以有可复用的方法，而不是每首歌重新摸索 |
| 节奏不稳、抢拍漏拍 | 节奏感训练 | 加餐课《告别抢拍漏拍，快速找准节奏感》 | 节奏问题也有专项训练入口 |
| 零基础、不知道怎么开始 | 简单动作、知识点拆解、歌曲实战、每日学习安排 | D1-D5 连续学习路径 | 先从身体通道与气息等基础能力开始，一步步进入唱歌训练 |
| 怕课程专业复杂 | 理论讲解 + 动作拆解 + 曲目实战 | D1-D5 | 把专业发声拆成普通人能理解和跟练的动作与歌曲练习 |
| 自学没人指导 | 班主任陪伴、带练、打卡、专业点评、答疑 | 体验营真实服务 | 不只是听课，还有练习与反馈环节 |

### 使用原则

1. Hero Strategy 必须优先选择与 `creative_intent` 最相关的 Supply，而不是罗列整个课程；
2. 如果广告只建立一个具体问题，不要把 Hero 扩大成“解决所有唱歌问题”；
3. 如果广告已经充分解释某个动作，Hero 应优先向“如何系统练 / 如何真正应用”推进，而不是机械重复；
4. Course Supply 是承接边界，不是强制把课程表塞进 Hero。

# 5. 5-Day Course Truth

## D1

课程方向：打开身体通道，减少大白嗓问题，找到丹田发力方向。

可用知识：

- 内鼻孔吸气；
- 气沉丹田；
- 拉皮筋式用力；
- 身体通道；
- 身体力量参与发声。

## D2

课程方向：稳固气息，帮助用户更敢开口唱。

可用知识：

- 内鼻孔吸气进阶训练；
- 啃苹果训练；
- 气息稳固；
- 跟练与开口唱。

## D3

课程方向：高位置演唱与高音。

可用知识：

- 横通道训练；
- 拓宽声音空间；
- 打开内口腔；
- 高位置发声；
- 歌曲实操带唱《鸿雁》。

## D4

课程方向：高低音转换与情感演唱。

可用知识：

- 低频 `wu` 音训练；
- 高位置发声训练；
- 高低音转换；
- 情感表达。

## D5

课程方向：通俗歌曲学习中的可复用方法。

可用知识：

- 气包声；
- 高位置稳定训练；
- 新歌学习方法；
- 歌曲实战。

## 加餐 / 福利课程

可作为 Supporting Supply，不默认成为 Hero Primary Message：

- 节奏训练：减少抢拍漏拍；
- 挤嗓 / 卡嗓方向的发声训练。

# 9. Compliance & Copy Rules

## 9.1 绝对化 / 极限词禁止

禁止在任何 Hero 文案中使用或变体使用：

- 最、最佳、最好、最优、最大、最强；
- 第一、唯一、首选；
- 顶级、顶尖、极致、绝对；
- 国家级、世界级；
- 全网最低、史无前例；
- 万能；
- 全国领先、全国第一；
- 首席、冠军、先行者。

注意：课程内部名称中历史上存在“万能功法”等表达，不代表 Hero Copy 可直接使用“万能”作为营销承诺。

## 9.2 虚假 / 夸大承诺禁止

禁止：

- 保证、保证效果；
- 100%；
- 包教包会、包学会；
- 永远；
- 根治；
- 一步到位；
- 速成；
- 立竿见影；
- 药到病除；
- 零风险；
- 无副作用；
- “有效”作为无条件效果保证。

## 9.3 权威滥用禁止

禁止无依据或无必要地使用：

- 驰名商标；
- 国家认可；
- 央视推荐；
- 政府指定；
- 专家推荐；
- 名医 / 大师；
- 人民大会堂等场景作为课程效果背书。

## 9.4 恐惧 / 诱导营销禁止

禁止：

- 不买后悔；
- 错过再无；
- 限时秒杀；
- 仅剩 X 名额；
- 不买就亏；
- 别人都在学；
- 不学就落后；
- 用疾病、衰老、死亡制造恐惧。

## 9.5 健康 / 医疗类内容处理

课程说明书中存在改善肺功能、预防认知退化、抗衰老、更年期等内部产品背景内容。

这些内容在本知识库中的默认 `usage_scope = forbidden_for_hero`。

不得默认生成：

- 改善肺功能；
- 预防 / 减缓老年痴呆；
- 抗衰老；
- 改善更年期；
- 治疗咽炎或其他疾病；
- 任何疾病治疗 / 康复承诺。

只有后续明确经过合规审核并加入白名单，才可改变该状态。

## 9.6 中性“改善”规则

允许：

- 改善唱功；
- 改善大白嗓问题；
- 改善气息使用；
- 改善错误发声方式。

禁止用“改善”暗示疾病疗效，例如改善失眠、改善慢性病等。

## 9.7 CTA / Hero 行动文案

当前 Hero 内容策略层默认不使用：

- 立即；
- 点击；
- 报名；
- 试听；
- 强制领取型行动词。

最终 CTA 由页面既有模板 / 实验规则负责，不应由 V2.2 Hero Strategy 擅自改写。

# 11. V2.2 Consumption Rules

V2.2 Hero Strategy 应按以下顺序使用知识：

```text
creative_intent.primary_driver
        +
creative_intent.unresolved_question
        ↓
匹配 5-Day Course Supply
        ↓
选择最相关、最可兑现的下一步信念
        ↓
应用 Compliance / Teacher / Scope Gate
        ↓
hero_strategy.json
```

核心公式：

```text
Hero Strategy
=
Primary Driver 已建立的信念
+
Unresolved Question
+
5-Day Experience Camp 能真实提供的下一步答案
+
Control Hero 销售骨架约束
```

### V2.2 必须遵守

1. 不能只把 Primary Driver 改写一遍；
2. 不能凭空创造 5 天体验营没有的课程能力；
3. 不能引用正式营产品、价格、服务或福利；
4. 不能为了 Message Match 牺牲合规；
5. 老师身份默认是 Trust，不自动成为 Primary Message；
6. Course Supply 只解决“这个课程能真实回答什么”，不替代 Creative Intent；
7. 一次只选择最相关的 1 个 Primary Message Direction，Supporting Messages 控制数量；
8. 如果 Unresolved Question 超出 5 天体验营可兑现范围，应收缩策略，而不是创造新承诺。

# 12. V2.3 Consumption Rules

V2.3 可以把 V2.2 Strategy 写成具体文案，但必须同时受以下约束：

- 只使用 `hero_safe` Product Truth；
- 不把 `supporting_only` 自动升级成 Headline；
- 不输出 `forbidden` / `compliance_review` 内容，除非已有额外授权；
- 严格执行违禁词规则；
- 课程歌曲只从人工确认的 Song Display Whitelist 中选；
- 不自动声称白名单歌曲全部属于 5 天核心课程；
- 不生成正式营信息。

V1 历史文案长度可作为后续 V2.3 参考，而不是 V2.2 Strategy 的强约束：

- 主标题：历史参考 ≤10 字；
- 副标题 / 定位语：历史参考 ≤12 字；
- 效果标签：历史参考每条 ≤4 字；
- 痛点 / 卖点短句：历史参考每条 ≤8 字；
- 价值承诺语：历史参考 ≤18 字。

最终长度应结合真实 Control Hero Slot 再冻结。
